**Контрольные вопросы**


1. **Какой тип раздела используется в разделе GUID для работы с LVM?**

В GPT-разметке для LVM используется **GUID‑тип раздела LVM**:  
`E6D6D379-F507-44C2-A23C-238F2A3DF928`  




2. **Какой командой можно создать группу томов с именем vggroup, которая содержит физическое устройство /dev/sdb3 и использует физический экстент 4 MiB?**

```bash
vgcreate -s 4M vggroup /dev/sdb3
```

- `-s 4M` — размер физического экстента 4 MiB  
- `vggroup` — имя группы томов  
- `/dev/sdb3` — физический том (раздел) для включения в группу



3. **Какая команда показывает краткую сводку физических томов в вашей системе, а также группу томов, к которой они принадлежат?**

Краткая сводка по физическим томам:

```bash
pvs
```

Более детальная информация:

```bash
pvdisplay
```

Но именно «краткая сводка» — это `pvs`.


4. **Что вам нужно сделать, чтобы добавить весь жёсткий диск /dev/sdd в группу томов?**

Последовательность действий:

1. Сначала создать на диске физический том LVM:

   ```bash
   pvcreate /dev/sdd
   ```

2. Затем добавить этот физический том в существующую группу томов, например `vggroup`:

   ```bash
   vgextend vggroup /dev/sdd
   ```

Если вопрос в контексте одной уже существующей VG, формулируют именно так:  
**pvcreate, затем vgextend**.



5. **Какая команда позволяет вам создать логический том lvvol1 с размером 6 MiB?**

Предположим, что группа томов называется `vggroup`:

```bash
lvcreate -L 6M -n lvvol1 vggroup
```

- `-L 6M` — размер логического тома 6 MiB  
- `-n lvvol1` — имя логического тома  
- `vggroup` — группа томов, в которой создаётся логический том



6. **Какая команда позволяет вам добавить 100 МБ в логический том lvvol1, если дисковое пространство доступно в группе томов?**

Дополнить (увеличить) существующий логический том на 100 MiB:

```bash
lvextend -L +100M /dev/vggroup/lvvol1
```

или эквивалентно:

```bash
lvextend -L +100M vggroup/lvvol1
```

Знак `+` означает «увеличить на», а не «сделать размер равным».



7. **Каков первый шаг, чтобы добавить ещё 200 МБ дискового пространства в логический том, если требуемое дисковое пространство недоступно в группе томов?**

Если в группе томов **нет свободного места**, то первым шагом нужно:

1. **Добавить новое физическое устройство в LVM**, то есть:
   - создать на нём физический том:

     ```bash
     pvcreate /dev/sdX
     ```

   - расширить группу томов за счёт этого физического тома:

     ```bash
     vgextend vggroup /dev/sdX
     ```

Формально «самый первый шаг» — **создать новый физический том (pvcreate)**, потом уже `vgextend`, а затем `lvextend`.


8. **Какую опцию нужно использовать с командой lvextend, чтобы также изменить размер файловой системы?**

Нужна опция:

```bash
-r
```

Пример:

```bash
lvextend -r -L +100M /dev/vggroup/lvvol1
```

`-r` (или `--resizefs`) говорит LVM автоматом увеличить и файловую систему на томе (если она поддерживается).


9. **Как посмотреть, какие логические тома доступны?**

Краткая сводка логических томов:

```bash
lvs
```

Более подробный вывод:

```bash
lvdisplay
```



10. **Какую команду нужно использовать для проверки целостности файловой системы на /dev/vgdata/lvdata?**

Это делается с помощью `fsck`. Чаще всего явно указывают тип файловой системы (`ext4`, `xfs` и т.п.). Для классического `ext4`:

```bash
fsck -f /dev/vgdata/lvdata
```

или более конкретно (если известно, что это ext4):

```bash
e2fsck -f /dev/vgdata/lvdata
```
