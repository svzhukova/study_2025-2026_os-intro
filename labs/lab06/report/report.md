**Контрольные вопросы**


1. **Команда для обзора всех текущих заданий оболочки**: 
   ```bash
   jobs
   ```

2. **Как остановить текущее задание оболочки, чтобы продолжить его выполнение в фоновом режиме**:
   Нажмите `Ctrl + Z`, чтобы приостановить задание, а затем используйте:
   ```bash
   bg %job_number
   ```
   где `job_number` — это номер задания, который можно получить с помощью `jobs`.

3. **Комбинация клавиш для отмены текущего задания оболочки**:
   ```plaintext
   Ctrl + C
   ```

4. **Что можно сделать, чтобы отменить задание, когда доступ к оболочке невозможен**:
   Если доступ к оболочке невозможен, можно использовать команду `kill` с идентификатором процесса (PID):
   ```bash
   kill PID
   ```
   Или, если это не сработает, использовать `kill -9 PID` для принудительного завершения процесса.

5. **Команда для отображения отношений между родительскими и дочерними процессами**:
   ```bash
   ps -ef --forest
   ```

6. **Команда для изменения приоритета процесса с идентификатором 1234 на более высокий**:
   ```bash
   renice -n -5 -p 1234
   ```
   Здесь `-n -5` означает, что приоритет будет повышен (отрицательное значение).

7. **Как проще всего остановить все процессы dd**:
   Используйте:
   ```bash
   pkill dd
   ```

8. **Команда, позволяющая остановить команду с именем mycommand**:
   ```bash
   pkill mycommand
   ```

9. **Команда в `top`, чтобы убить процесс**:
   Нажмите `k`, затем введите PID процесса и подтвердите.

10. **Как запустить команду с высоким приоритетом, не рискуя нехваткой ресурсов для других процессов**:
    Запустить команду с использованием `nice`, например:
    ```bash
    nice -n -10 mycommand
    ```
    Однако стоит помнить о том, что необходимо следить за нагрузкой на систему.
