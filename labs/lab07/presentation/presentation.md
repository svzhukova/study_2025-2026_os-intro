## Постоянный журнал journald

По умолчанию журнал journald хранит сообщения в оперативной памяти системы
и записи доступны в каталоге /run/log/journal только до перезагрузки системы. Для
того чтобы сделать журнал journald постоянным, выполним следующие действия.

1. Запустим терминал и получим полномочия администратора.
2. Создадим каталог для хранения записей журнала.
3. Скорректируем права доступа для каталога /var/log/journal, чтобы journald смог записывать в него информацию

![журнал journald постоянным](image/30.png){#fig:030 width=70%}
