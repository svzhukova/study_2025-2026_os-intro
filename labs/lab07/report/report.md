2. Создадим каталог для хранения записей журнала.
3. Скорректируем права доступа для каталога /var/log/journal, чтобы journald смог записывать в него информацию (рис. [-@fig:030]).

**Контрольные вопросы**

### 1. Какой файл используется для настройки rsyslogd?
Основной файл конфигурации для `rsyslogd` — это **`/etc/rsyslog.conf`**. Дополнительно, настройки могут находиться в директории **`/etc/rsyslog.d/`**, где можно добавлять файлы конфигурации с расширением `.conf`.

### 2. В каком файле журнала rsyslogd содержатся сообщения, связанные с аутентификацией?
Сообщения, связанные с аутентификацией, обычно находятся в файле **`/var/log/auth.log`** или **`/var/log/secure`** (в зависимости от дистрибутива Linux).

### 3. Если вы ничего не настроите, то сколько времени потребуется для ротации файлов журналов?
По умолчанию ротация файлов журналов на большинстве систем Linux производится ежедневно. Это управляется с помощью `logrotate`, который по умолчанию запускается через cron раз в день.

### 4. Какую строку следует добавить в конфигурацию для записи всех сообщений с приоритетом info в файл `/var/log/messages.info`?
Можно добавить следующую строку в конфигурации `rsyslogd`:

```bash
*.info /var/log/messages.info
```

### 5. Какая команда позволяет вам видеть сообщения журнала в режиме реального времени?
Для просмотра сообщений журнала в реальном времени можно использовать команду:

```bash
tail -f /var/log/syslog
```

Или, если используется `journalctl`:

```bash
journalctl -f
```

### 6. Какая команда позволяет вам видеть все сообщения журнала, которые были написаны для PID 1 между 9:00 и 15:00?
Можно использовать следующую команду:

```bash
journalctl --pid=1 --since "today 09:00" --until "today 15:00"
```

### 7. Какая команда позволяет вам видеть сообщения journald после последней перезагрузки системы?
Для просмотра сообщений `journald` после последней перезагрузки системы используйте:

```bash
journalctl -b
```

### 8. Какая процедура позволяет сделать журнал journald постоянным?
Чтобы сделать журнал `journald` постоянным, необходимо создать или изменить файл конфигурации **`/etc/systemd/journald.conf`** и установить параметр `Storage` в значение `persistent`. Затем нужно перезапустить службу `systemd-journald`:

```bash
sudo systemctl restart systemd-journald
```
