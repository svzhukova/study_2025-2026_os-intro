Команда `chronyc sources` показывает источники времени, с которыми синхронизируется сервер или клиент.

- **MS** - состояние источника. `^*` означает основной выбранный сервер, `^-` - доступный, но не выбранный.
- **Name/IP address** - имя или IP-адрес NTP-сервера.
- **Stratum** - уровень источника времени. Чем меньше число, тем ближе он к эталонным часам.
- **Poll** - интервал опроса сервера (6 = 64 секунды, 7 = 128 секунд).
- **Reach** - доступность сервера. `377` означает, что все последние 8 проверок прошли успешно.
- **LastRx** - сколько секунд назад был получен последний ответ.
- **Last sample** - отклонение локального времени от времени источника и погрешность измерения.

**Вывод:** в примере доступны четыре источника времени. Основным выбран `lipinr.ru` (обозначен `^*`). Остальные серверы доступны и могут служить дополнительными источниками синхронизации.

# Выводы

Мы получили навыки по управлению системным временем и настройке синхронизации времени.

**Контрольные вопросы**

1. **Почему важна точная синхронизация времени для служб баз данных?**

   Для правильной фиксации времени создания и изменения записей, упорядочивания транзакций, ведения журналов и предотвращения ошибок при обмене данными между серверами.
2. **Почему Kerberos зависит от правильной синхронизации времени?**

   Kerberos использует временные метки для проверки подлинности билетов. Если время на клиенте и сервере сильно различается, аутентификация может завершиться ошибкой.
3. **Какая служба используется по умолчанию для синхронизации времени на RHEL 7?**

   Chrony (`chronyd`).
4. **Какова страта по умолчанию для локальных часов?**

   Stratum 10.
5. **Какой порт брандмауэра должен быть открыт для сервера NTP?**

   UDP-порт 123.
6. **Какую строку нужно добавить в конфигурацию Chrony, чтобы сервер работал даже без внешних NTP-серверов?**
   ```
   local stratum 10
   ```
7. **Какую страту имеет хост, если нет текущей синхронизации NTP?**

   Stratum 10, если настроена директива `local stratum 10`. Без неё хост не имеет действующего источника синхронизации.
8. **Какой командой узнать, с какими серверами синхронизируется Chrony?**
   ```
   chronyc sources
   ```
9. **Как получить подробную статистику текущих настроек времени Chrony?**
   ```
   chronyc tracking
   ```
   Команда показывает источник времени, страту, отклонение часов, частотные поправки и состояние синхронизации.
