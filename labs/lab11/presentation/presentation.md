## Настройка удалённого доступа по SSH по ключу

В этом упражнении создаём пару из открытого и закрытого ключей для входа на
сервер.
На сервере в конфигурационном файле /etc/ssh/sshd_config зададим параметр,
разрешающий аутентификацию по ключу, на клиенте сформируем SSH-ключ
Закрытый ключ теперь будет записан в файл ~/.ssh/id_rsa, а открытый ключ записывается в файл ~/.ssh/id_rsa.pub.

Скопируем открытый ключ на сервер, попробуем получить доступ с клиента к серверу посредством SSH-соединения
Теперь мы проходим аутентификацию без ввода пароля для учётной записи удалённого пользователя. 

![ключ](image/11.png){#fig:011 width=70%}
