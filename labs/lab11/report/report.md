# Выводы

Мы приобрели практические навыки по настройке удалённого доступа к серверу с помощью SSH.

**Контрольные вопросы**



**1. Как запретить удалённый доступ по SSH пользователю root и разрешить доступ пользователю alice?**

Необходимо отредактировать конфигурационный файл SSH-сервера:

```
sudo nano /etc/ssh/sshd_config
```

Добавить или изменить следующие параметры:

```
PermitRootLogin no
AllowUsers alice
```

- `PermitRootLogin no` — запрещает пользователю root входить по SSH.
- `AllowUsers alice` — разрешает подключение только пользователю alice.

После изменения конфигурации перезапустить SSH:

```
sudo systemctl restart sshd
```

**2. Как настроить удалённый доступ по SSH через несколько портов? Для чего это может потребоваться?**

Необходимо открыть файл конфигурации:

```
sudo nano /etc/ssh/sshd_config
```

Указать несколько директив `Port`:

```
Port 22
Port 2022
Port 2222
```

Перезапустить SSH:

```
sudo systemctl restart sshd
```

Несколько портов могут потребоваться для:

- обеспечения совместимости со старыми подключениями;
- постепенного перехода на новый порт;
- организации доступа для разных пользователей или служб;
- использования альтернативного порта, если стандартный порт 22 заблокирован.

**3. Какие параметры используются для создания туннеля SSH, когда команда ssh устанавливает фоновое соединение и не ожидает какой-либо конкретной команды?**

Используются следующие параметры:

```
ssh -f -N user@server
```

- `-f` — переводит SSH в фоновый режим.
- `-N` — не выполняет удалённую команду, а только устанавливает соединение.

Обычно эти параметры применяются для создания SSH-туннелей и перенаправления портов.

**4. Как настроить локальную переадресацию с локального порта 5555 на порт 80 сервера server2.example.com?**

Используется параметр `-L`:

```
ssh -L 5555:server2.example.com:80 user@server
```

Где:

- `5555` — локальный порт компьютера.
- `server2.example.com` — удалённый сервер, к которому выполняется переадресация.
- `80` — порт веб-сервера.

После подключения можно открыть в браузере:

```
http://localhost:5555
```

Запросы будут проходить через SSH-соединение к порту 80 сервера `server2.example.com`.

**5. Как настроить SELinux, чтобы позволить SSH связываться с портом 2022?**

Сначала проверить, установлен ли пакет для управления портами SELinux:

```
sudo dnf install policycoreutils-python-utils
```

Добавить порт 2022 в список разрешённых для SSH:

```
sudo semanage port -a -t ssh_port_t -p tcp 2022
```

Проверить результат:

```
sudo semanage port -l | grep ssh
```

Если порт уже существует в конфигурации SELinux с другим типом, вместо `-a` необходимо использовать `-m`.

**6. Как настроить межсетевой экран на сервере, чтобы разрешить входящие подключения по SSH через порт 2022?**

Если используется `firewalld`, необходимо выполнить команды:

Добавить порт 2022 в разрешённые:

```
sudo firewall-cmd --permanent --add-port=2022/tcp
```

Применить изменения:

```
sudo firewall-cmd --reload
```

Проверить настройки:

```
sudo firewall-cmd --list-ports
```

Если SSH работает через порт 2022, также необходимо убедиться, что в `/etc/ssh/sshd_config` указано:

```
Port 2022
```

И перезапустить службу:

```
sudo systemctl restart sshd
```
