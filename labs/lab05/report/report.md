# Контрольные вопросы

1. **Что такое юнит (unit)? Приведите примеры.**

   Юнит — это основной элемент управления в системе инициализации systemd. Каждый юнит представляет собой конфигурационный файл, который описывает объект, например, службу, таймер, точку монтирования или цель (target). Примеры юнитов:
   - **Службы (service)**: `ssh.service` — отвечает за запуск сервера SSH.
   - **Цели (target)**: `multi-user.target` — указывает на состояние системы, в котором она готова выполнять многопользовательские задачи.
   - **Точки монтирования (mount)**: `media-usb.mount` — описывает точку монтирования USB-накопителя.

2. **Какая команда позволяет вам убедиться, что цель больше не входит в список автоматического запуска при загрузке системы?**

   Команда: 
   ```bash
   sudo systemctl disable <имя_цели>
   ```
   Эта команда отключает автоматический запуск указанной цели при загрузке системы.

3. **Какую команду вы должны использовать для отображения всех сервисных юнитов, которые в настоящее время загружены?**

   Команда: 
   ```bash
   systemctl list-units --type=service
   ```
   Она отображает все текущие активные юниты типа "service".

4. **Как создать потребность (wants) в сервисе?**

   Для создания зависимости типа "wants" следует использовать:
   ```bash
   sudo systemctl enable <имя_сервиса>.wants.<имя_цели>
   ```
   Это создаст символическую ссылку в директории `wants`, обеспечивающую запуск сервиса при старте цели.

5. **Как переключить текущее состояние на цель восстановления (rescue target)?**

   Команда для переключения на цель восстановления:
   ```bash
   sudo systemctl isolate rescue.target
   ```
   Эта команда переключает систему в режим восстановления, где используется минимальный набор сервисов.

6. **Поясните причину получения сообщения о том, что цель не может быть изолирована.**

   Сообщение о том, что цель не может быть изолирована, возникает, когда активные юниты или сервисы зависят от этой цели. Например, если запущены сервисы, которые "зависят" от цели, их нельзя отключить, так как это приведет к нестабильности или потере данных.

7. **Вы хотите отключить службу systemd, но, прежде чем сделать это, вы хотите узнать, какие другие юниты зависят от этой службы. Какую команду вы бы использовали?**

   Для отображения зависимостей юнита используется:
   ```bash
   systemctl list-dependencies <имя_сервиса>
   ```
   Эта команда выводит все юниты, которые зависят от указанной службы.
