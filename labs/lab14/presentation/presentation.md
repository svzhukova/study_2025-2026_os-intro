## Ручное монтирование файловых систем

Для ручной установки файловой системы используется команда mount. Чтобы отключить смонтированную файловую систему, используется команда umount.
Чтобы смонтировать файловую систему, используйте следующую команду
mount /dev/sdb5 /mnt/tmp 

![Чтобы отмонтировать раздел, можно использовать umount либо с именем устройства, либо с именем точки монтирования.](image/20.png){#fig:020 width=70%}
